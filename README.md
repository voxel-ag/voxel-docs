# Voxel docs

Public documentation for Voxel, the Solana swap aggregator, built with [Mintlify](https://mintlify.com).

## Layout

| Path | Contents |
|---|---|
| `docs.json` | Mintlify site configuration and navigation |
| `*.mdx` | Introduction, quickstart, routing, venues, errors, support |
| `api/` | One page per public endpoint |
| `guides/` | Integration guide and app guide |
| `logo/`, `images/`, `favicon.png` | Brand assets |

## Preview

```bash
npm i -g mint
mint dev
```
